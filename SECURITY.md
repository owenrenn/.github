# Security Policy

## Reporting a vulnerability

These are personal / small-studio projects. If you find a security issue,
please report it **privately** — do not open a public issue.

- **Preferred:** the repository's **Security → Report a vulnerability** tab
  (GitHub private vulnerability reporting), where enabled.
- **Alternatively:** open a minimal private channel with the maintainer.

Please include what you found, how to reproduce it, and the impact. I'll
acknowledge and triage on a best-effort basis.

## Supported versions

Only the **latest release** of each project is supported. There is no
back-porting of fixes to older tags.
